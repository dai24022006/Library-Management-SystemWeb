# Library Management SystemWeb

## 1. Giới thiệu

Library Management SystemWeb là hệ thống quản lý thư viện được xây dựng bằng Spring Boot, MySQL và HTML/CSS/JavaScript.

Hệ thống hỗ trợ quản lý sách, độc giả, phiếu mượn và trả sách, đồng thời theo dõi tình trạng mượn và xử lý các khoản phí phát sinh.

## 2. Chức năng chính

### Quản lý sách

* Thêm, sửa, xem và tìm kiếm sách.
* Quản lý số lượng và tình trạng sách.
* Xóa mềm sách theo quy tắc của hệ thống.

### Quản lý độc giả

* Thêm, sửa và tìm kiếm độc giả.
* Quản lý thông tin độc giả.
* Xóa mềm độc giả.

### Quản lý mượn và trả sách

* Lập phiếu mượn gồm nhiều đầu sách.
* Theo dõi ngày mượn và hạn trả.
* Xử lý trả sách, sách hỏng và sách mất.
* Theo dõi phiếu đang mượn, đã trả và quá hạn.
* Tính phí phát sinh và lập hóa đơn khi trả sách.

## 3. Công nghệ sử dụng

* Backend: Java, Spring Boot
* Database: MySQL
* Frontend: HTML, CSS, JavaScript
* API: REST API
* Build tool: Maven

## 4. Yêu cầu môi trường

* JDK 21
* MySQL 8
* Maven

## 5. Cài đặt và chạy dự án

1. Clone repository.
2. Tạo database theo cấu hình dự án.
3. Cấu hình thông tin kết nối database.
4. Chạy ứng dụng Spring Boot.
5. Mở giao diện frontend theo cách triển khai của dự án.

## 6. Cấu trúc dự án

Mô tả các thư mục chính của backend và frontend.

## 7. API

Liệt kê các endpoint chính, phương thức HTTP và chức năng.
